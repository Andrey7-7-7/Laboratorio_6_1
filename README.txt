DESCRIPCIÓN DEL PROYECTO

Este proyecto consiste en una página web educativa creada con HTML5, CSS, Bootstrap y JavaScript. Su objetivo es demostrar conceptos básicos de programación mediante ejemplos interactivos y un diseño adaptable a diferentes tamaños de pantalla.

CONTENIDO DEL PROYECTO

* index.html: contiene la estructura semántica de la página y conecta las hojas de estilo y los archivos JavaScript.
* style.css: define los colores, las tarjetas, los espacios y los estilos responsivos.
* script.js: contiene los ejemplos de programación.
* images/javascript.svg: icono del proyecto.

CONCEPTOS DEMOSTRADOS

1. Declaración de variables y tipos de datos.
2. Uso de arreglos y objetos.
3. Condicionales if, else if y else.
4. Bucles for, while y do...while.
5. Iteración de arreglos mediante forEach.
6. Creación y uso de funciones.
7. Alcance de las variables.
8. Clausuras o closures.
9. Uso de console.log() para verificar resultados.
10. Diseño responsivo y elementos de accesibilidad.

TECNOLOGÍAS UTILIZADAS

HTML5, CSS3, Bootstrap 5 y JavaScript.

PRUEBAS

La página permite ejecutar ejemplos desde el navegador y observar los resultados en la interfaz y en la consola de desarrollador.
